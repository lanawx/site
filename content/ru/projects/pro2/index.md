## Введение

Удалённая работа с серверами — неотъемлемая часть работы исследователя и разработчика. Правильная настройка SSH, использование tmux для долгих сессий и соблюдение мер безопасности позволяют работать эффективно и не терять прогресс даже при разрывах соединения.

## SSH: безопасное подключение к удалённому серверу

SSH (Secure Shell) — протокол для безопасного удалённого управления серверами.

### Базовая команда подключения

ssh username@server_ip_or_domain

### Настройка SSH-ключей для входа без пароля

Генерация ключевой пары (на локальной машине):
ssh-keygen -t ed25519 -C "your_email@example.com"

Копирование публичного ключа на сервер:
ssh-copy-id username@server_ip

После этого вход будет происходить без запроса пароля.

### Отключение входа по паролю на сервере (для усиления безопасности)

Редактировать файл /etc/ssh/sshd_config:
PasswordAuthentication no
PubkeyAuthentication yes

Затем перезапустить SSH: sudo systemctl restart sshd

### Проброс портов (туннелирование)

Локальный проброс (доступ к удалённому сервису через локальный порт):
ssh -L 8080:localhost:80 username@server_ip

Удалённый проброс (доступ к локальному сервису с сервера):
ssh -R 9090:localhost:3000 username@server_ip

## tmux: терминальный мультиплексор

tmux позволяет создавать и управлять несколькими сессиями терминала, которые продолжают работать после отключения от сервера.

### Основные команды

Создать новую сессию: tmux new -s session_name

Отсоединиться от сессии (сессия остаётся в фоне): Ctrl+B, затем D

Посмотреть список сессий: tmux ls

Подключиться к существующей сессии: tmux attach -t session_name

Убить сессию: tmux kill-session -t session_name

### Горячие клавиши внутри сессии (префикс Ctrl+B по умолчанию)

Создать новое окно: Ctrl+B, затем C

Переключиться между окнами: Ctrl+B, затем номер окна (0, 1, 2...) или Ctrl+B, затем N (следующее) / P (предыдущее)

Разделить панель горизонтально: Ctrl+B, затем "

Разделить панель вертикально: Ctrl+B, затем %

Переключиться между панелями: Ctrl+B, затем стрелки

Закрыть текущую панель: Ctrl+B, затем X (подтвердить Y)

### Пример рабочего процесса

Подключиться к серверу через SSH, запустить tmux new -s research, внутри запустить долгий расчёт (например, python train_model.py), отсоединиться от сессии (Ctrl+B, затем D), закрыть SSH-соединение. Через несколько часов снова подключиться к серверу через SSH и выполнить tmux attach -t research, чтобы увидеть прогресс расчёта.

## Дополнительные меры безопасности

Использовать нестандартный порт для SSH (изменить Port 22 на Port 2222 в /etc/ssh/sshd_config). Запретить вход для root (PermitRootLogin no). Использовать Fail2ban для блокировки IP после нескольких неудачных попыток входа. Регулярно обновлять SSH-сервер (sudo apt update && sudo apt upgrade openssh-server). Настроить двухфакторную аутентификацию (google-authenticator).

## Полезные команды для диагностики

Проверка активных SSH-подключений на сервере: who | grep pts

Проверка логов SSH: sudo journalctl -u ssh -f

Тестирование подключения с подробным выводом: ssh -vvv username@server_ip
