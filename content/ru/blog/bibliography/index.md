## Введение

Грамотное оформление библиографии — основа научной работы. Современные инструменты позволяют автоматизировать сбор, хранение и цитирование источников.

## Системы управления библиографией

| Инструмент | Платформы | Импорт из DOI/BibTeX | Бесплатный | Интеграция с Word/Google Docs |
|---|---|---|---|---|
| **Zotero** | Windows, Mac, Linux, Web | Да | Да (до 300 МБ облачного хранилища) | Да |
| **Mendeley** | Windows, Mac, Linux, Web | Да | Да (2 ГБ облачного хранилища) | Да |
| **EndNote** | Windows, Mac, Web | Да | Нет (платный) | Да |
| **JabRef** | Java (кроссплатформенный) | Да | Да | Ограниченная |

## Интеграция с Hugo Academic

В теме `wowchemy/starter-hugo-academic` поддерживается автоматический импорт публикаций из файла `.bib` (BibTeX).

1. **Экспортировать публикации** из Zotero/Mendeley в формате BibTeX (`.bib`).

2. **Поместить файл** `publications.bib` в папку `assets/` или `data/`.
