## Введение

Научное программирование — важный инструмент современного исследователя. Правильный выбор языка позволяет ускорить обработку данных, визуализацию и анализ результатов.

## Обзор языков

### Python

**Плюсы:**
- Огромная экосистема библиотек: NumPy, SciPy, Matplotlib, Pandas, Scikit-learn.
- Простота изучения и читаемый код.
- Активное сообщество.

**Минусы:**
- Медленнее компилируемых языков (но есть Cython, Numba, PyPy).

**Пример кода** (численное интегрирование):
```python
import numpy as np

def f(x):
    return x**2

result = np.trapz([f(x) for x in np.linspace(0, 1, 100)])
print(result)  # ≈ 0.33335
