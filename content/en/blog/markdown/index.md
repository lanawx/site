## What are markup languages?

Markup languages are a way to describe the structure and formatting of a document using special symbols. Unlike visual editors (Word, Google Docs), you write plain text, and then a program converts it into the final format — HTML, PDF, DOCX, and others.

## Markdown

The most popular lightweight markup language. Used everywhere: GitHub, Notion, Obsidian, chats, blogs.

Features:
- Syntax can be learned in 10 minutes
- No compilation required
- Easily converts to HTML/PDF
