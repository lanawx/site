## What is Git?

Git is a distributed version control system that allows you to track changes in files and coordinate work on projects among multiple people.

## Basic Git Commands

```bash
# Initialize a repository
git init

# Add files to the staging area
git add .

# Create a commit
git commit -m "Commit message"

# Push changes to a remote repository
git push origin main

# Pull changes from a remote repository
git pull origin main
